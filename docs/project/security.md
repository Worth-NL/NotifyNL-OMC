# Security policy

## Supported versions

Only the latest tagged release receives security updates.

## Reporting a vulnerability

If you discover a security vulnerability, **do not open a public GitHub issue**. Instead:

1. Email [info@worth.nl](mailto:info@worth.nl) with:
   - A detailed description of the vulnerability
   - Steps to reproduce
   - Potential impact or risk
   - Your contact information (optional)

2. We will acknowledge receipt, investigate, and release a fix as soon as possible.

We are committed to responsible disclosure and will work with reporters to ensure vulnerabilities are addressed promptly and transparently.

## Contact

Security questions or concerns: [info@worth.nl](mailto:info@worth.nl)
